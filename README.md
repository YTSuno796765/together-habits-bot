# Together Habits Bot

Telegram-бот — трекер привычек, которые проще держать вместе.

## Режимы

| Режим | Что внутри |
|---|---|
| 🤝 **С другом** | Общие привычки, уведомления «друг уже отметился — твоя очередь», совместные серии 🔥, синхронность. |
| 💞 **Для пары** | Привычки, которые сближают (прогулка вместе, комплимент, ужин без телефонов…), ежедневный трекер настроения 😞→😄 и «совместимость» пары. |
| 🎯 **Личный рост** | Личные привычки для успеха: подъём, тренировка, чтение, медитация, учёт расходов и свои. |

## 📱 Mini App

Внутри бота есть приложение: кнопка **«Привычки»** рядом с полем ввода
или **«📱 Открыть приложение»** в меню. В нём:

- прогресс дня и карточки привычек с полосками недели и серией 🔥;
- отметка выполнения одним нажатием (с вибрацией), у общих привычек видно, кто уже отметился;
- компактные квадратные карточки, по две в ряд;
- настройки разделов ⚙️: свои названия вкладок («С другом» → «С Мишей»),
  скрытие ненужного раздела и разрыв связки; у каждого участника свои;
- закрепление 📌 (закреплённые — отдельным блоком сверху) и порядок
  привычек перетаскиванием; у общих привычек порядок общий для обоих;
- раздел **«Не делать»** во всех режимах (курить, сладкое, думскроллинг…):
  каждый день засчитывается сам, отмечать нужно только срыв — серия
  «без срыва» обнуляется, а в парном режиме второй получает «поддержи 🤝»;
- расписание по дням недели: «каждый день», «будни», «вт, чт, сб»… — или
  **«N раз в неделю»** без конкретных дней: отмечаешь в любые дни, пропуски
  не краснеют, на карточке прогресс «2/3», серия считается в неделях;
- статистика: % за 7 и 30 дней, лучшая серия, графики по дням и по дням недели;
- для пары — настроение дня, настроение за неделю и совместимость;
- вкладка **«Планы»**: общий календарь планов с другом и с парой (разные
  цвета, неподтверждённые — пустые кружки). Предложение приходит второму
  сообщением в бота с кнопками «Принять / Отклонить» (ответить можно и в
  приложении), автор получает ответ; свой план можно отменить;
- приглашение друга или пары прямо из приложения.

### Продуктивность

- **Редактирование** привычки (название, иконка, дни, количество, цель, время),
  **отметка за вчера**, **архив** вместо удаления (с восстановлением).
- **Количественные привычки** — «8 стаканов воды», «30 минут чтения»: кнопка «+»
  с шагом, день засчитан, когда набрана норма.
- **Цель на привычку** — 21/30/66/100 дней или своя, прогресс на карточке.
- **Заметка** к дню («5 км за 28 минут») и история заметок.
- **Заморозка серии ❄️** — 2 в месяц на пропуски за последнюю неделю.
- **Челленджи 🏆** — 7/14/21/30 дней, «кто чаще» или «кто дольше без», со ставкой;
  вдвоём или компанией до 10 человек по ссылке, таблица лидеров, итоги в бот.
- **Пинок 👊** другу по общей привычке (раз в день) и **реакции** 🔥👏💪❤️😎.
- **Время для привычки** («Медитация в 07:00»), **напоминание о плане за час**,
  **повторяющиеся планы** (каждую неделю), **утренний план дня**,
  **итоги недели** по воскресеньям.
- **Главное сегодня** — до 5 задач на день, перенос невыполненных со вчера.
- **Помодоро ⏱** 15/25/45/60 минут, можно засчитать в привычку; бот напишет,
  когда время выйдет.
- **Цели на месяц/квартал 🚀** — число (5 кг) или прогресс привязанных привычек.
- **Статистика**: тепловая карта года и «Настроение и привычки» — как меняется
  настроение в дни с привычкой.
- **Экспорт CSV** (`/export`, кнопка в настройках, еженедельно по желанию) и
  резервная копия всей базы владельцу (`HABITS_ADMIN_ID`).

Все уведомления отправляет один планировщик раз в минуту (`scheduler.py`);
каждое записывается в таблицу `sent_log`, поэтому после перезапуска ничего не
приходит повторно.

Приложение — это статические файлы (`together_habits/webapp/`) и JSON API
в том же процессе, что и бот (aiohttp). Каждый запрос подписан Telegram
(`initData`), сервер проверяет подпись токеном бота, поэтому чужие данные
недоступны.

Общее для всех режимов:

- шаблоны привычек и свои привычки (можно с эмодзи: `🥗 Полезный завтрак`);
- отметка за сегодня одним нажатием;
- статистика: последние 7 дней, текущая серия и рекорд;
- ежедневные напоминания в выбранный час, только если остались неотмеченные привычки.

### Как считается

- **День в общем режиме** засчитывается, только когда отметились **оба**.
- **Серия** — подряд идущие выполненные дни. Если сегодня ещё не отмечено, серия не сгорает до конца дня.
- **Синхронность** (30 дней) — доля дней, когда хоть кто-то отметил привычку и это сделали оба.
- **Совпадение настроения** (30 дней) — доля дней, когда оба отметили настроение и оценки отличаются не больше чем на 1.
- **Совместимость** — среднее синхронности и совпадения настроения, от 0 до 100.

### Связка

Для режимов «С другом» и «Для пары» один человек нажимает «Пригласить» и
отправляет ссылку вида `https://t.me/<бот>?start=join_<код>`. Второй открывает
ссылку — связка готова. У каждого человека может быть одна связка «с другом» и
одна «для пары» одновременно.

## Запуск

Нужен Python 3.10+ и токен бота от [@BotFather](https://t.me/BotFather).

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
cp .env.example .env               # и впиши свой токен
python -m together_habits
```

Переменные окружения (`.env`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота (обязательно). |
| `HABITS_DB_PATH` | `habits.db` | Путь к файлу SQLite с данными. |
| `HABITS_TIMEZONE` | `Europe/Moscow` | Часовой пояс для «сегодня» и напоминаний. |
| `WEBAPP_URL` | — | Публичный HTTPS-адрес Mini App. Пусто — Mini App выключен. |
| `WEBAPP_HOST` / `WEBAPP_PORT` | `127.0.0.1` / `8080` | Где слушает веб-сервер Mini App. |
| `HABITS_ADMIN_ID` | — | Необязательно: твой числовой Telegram ID — раз в неделю бот пришлёт копию базы. |

Бот получает обновления опросом (`run_polling`), поэтому публичный адрес и
домен не нужны.

## Деплой на сервер

### Railway (всё из браузера, можно с телефона)

1. Зайди на [railway.com](https://railway.com) через GitHub и подключи тариф Hobby.
2. **New Project → Deploy from GitHub repo →** выбери `together-habits-bot`.
   Railway сам найдёт `Dockerfile` и `railway.json`.
3. В сервисе открой **Variables** и добавь `TELEGRAM_BOT_TOKEN` со своим токеном.
   По желанию добавь `HABITS_TIMEZONE`.
4. Добавь диск: правый клик по сервису (или `⌘K`) → **Add Volume** → mount path `/data`.
   Без диска база будет стираться при каждом деплое.
5. Дождись статуса **Active** и отправь боту `/start`.

Каждый пуш в `main` автоматически пересобирает бота. Держи **одну** реплику:
два экземпляра с одним токеном конфликтуют.

### VPS (Ubuntu/Debian)

Подключись к серверу по SSH (с телефона — например, через приложение Termius)
и выполни от root:

```bash
curl -fsSL https://raw.githubusercontent.com/YTSuno796765/together-habits-bot/main/scripts/install-vps.sh | bash
```

Скрипт установит Python, скачает код, спросит токен (ввод скрыт), сохранит
его в `/etc/together-habits.env` (права 600) и запустит бота как
systemd-сервис с автоперезапуском.

Для Mini App скрипт ставит [Caddy](https://caddyserver.com) и выдаёт
бесплатный HTTPS-адрес вида `https://1-2-3-4.sslip.io` (IP сервера через
дефисы), сертификат Caddy получает сам. Порты 80 и 443 должны быть открыты.

Чтобы обновить бота, запусти скрипт ещё раз. Логи:
`journalctl -u together-habits -f`, HTTPS: `journalctl -u caddy -n 30`.

## Команды

- `/start` — главное меню
- `/today` — отметить привычки за сегодня
- `/mood` — настроение (режим пары)
- `/export` — выгрузить свои данные в CSV
- `/help` — справка

## Разработка

```bash
pytest
scripts/verify-no-secrets.sh       # перед каждым коммитом
```

Структура:

```
together_habits/
  config.py     настройки из окружения
  db.py         SQLite: пользователи, связки, привычки, отметки, настроение
  logic.py      серии, статистика, совместимость (чистые функции)
  texts.py      тексты и шаблоны привычек
  keyboards.py  inline-клавиатуры
  handlers.py   обработчики Telegram
  webapp.py     API Mini App и проверка подписи Telegram
  scheduler.py  все уведомления по времени (раз в минуту, без повторов)
  reports.py    утренний план, итоги недели, экспорт CSV
  webapp/       интерфейс Mini App (HTML, CSS, JS без сборки)
  bot.py        сборка приложения, веб-сервер и напоминания
```
